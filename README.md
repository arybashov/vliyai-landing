# ВЛИЯЙ

Лендинг для амбассадоров. Логотип — «ВЛИЯЙ.» из брендбука. Текст перенесён из презентации XYZ без редакторских изменений.

Статическая страница: `index.html`, `styles.css`, `app.js`, `assets/`. Сборка и установка зависимостей не требуются.

Для локального просмотра: `python -m http.server 4173 --bind 127.0.0.1`.

GitHub Pages: публикация из корня ветки `main`.

Кнопки «Начать» ведут к разделу подключения. Адрес бота в исходных материалах не указан. Элементы «Одобрить», «Поправить», «Не моё» иллюстрируют интерфейс из презентации.

Исходные презентация и брендбук хранятся локально и не входят в репозиторий.
