# ВЛИЯЙ

Лендинг «ВЛИЯЙ — для брендов». Логотип — «ВЛИЯЙ.» из брендбука. 12 секций повторяют порядок и структуру презентации для брендов; текст перенесён без редакторских изменений.

Статическая страница: `index.html`, `styles.css`, `app.js`, `assets/`. Сборка и установка зависимостей не требуются.

Для локального просмотра: `python -m http.server 4173 --bind 127.0.0.1`.

GitHub Pages: публикация из корня ветки `main`.

Кнопка «Начать» ведёт к разделу «Что дальше?» с тремя шагами запуска и командой. Навигация ведёт к описанию платформы, областям применения, условиям кампании и принципам доверия.

Финансовые примеры представлены HTML-таблицей; на узком экране она прокручивается отдельно от страницы, в том числе с клавиатуры. Бегущая строка и сканирование фотографии сохранены. При включённом уменьшении движения анимации отключаются.

Исходные презентация и брендбук хранятся локально и не входят в репозиторий.
